# Simple Chatbot

A simple AI conversation app built with Python and a basic frontend. The project currently focuses on sending messages to an AI model and displaying the responses in a chat interface.

## Features

* Simple chat interface
* AI-powered conversations
* Python backend with FastAPI
* REST API for sending messages

## Tech Stack

* Python
* FastAPI
* OpenAI-compatible API
* HTML, CSS, JavaScript

## Status

🚧 **Work in Progress**

More features such as tool calling, memory, and other agent capabilities may be added in the future.
